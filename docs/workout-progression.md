# Workout progression
Levels N1–N3 reflect planned exposure to a phase (two loading weeks per level, recovery excluded), not measured adaptation. Peak uses N1; recovery uses easy endurance. Prescriptions increase work duration/repetitions rather than FTP percentages. Saved progressive sessions carry level and prescribedPhase, so reopening or changing the mesocycle does not silently alter the saved profile. Existing classic and long sessions remain compatible. Available time and remaining estimated load remain hard bounds for new automated structured workouts. A fixed group ride has unknown load and is preserved. Levels are coaching heuristics, not Friel-prescribed numbers; manual adjustment and confirmation remain necessary.
