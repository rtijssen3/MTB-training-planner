## Fitness-guided load (RC1)
The automatic four-completed-week 115% cap is removed from both weeks. Mesocycle target less completed load remains the upper budget. Fresh yesterday CTL/ATL anchor and actual today load (counted once) feed a daily exponential 42/7-day projection. Candidate additions and extensions use the same TSS recipe as the chart, including fixed/manual rides; prior week is carried into the next. Coaching heuristics: quality blocked below pre-session Form -10 or post-session -20; below -20 only light load (30 TSS maximum); below -30 only recovery (15 TSS maximum), no extra worsening on projected days below -30. These thresholds are heuristics, not physiological or injury-risk limits. Fixed/manual rides stay, with warning if low projected Form. Missing yesterday wellness or unknown actual load -> no forecast, use existing phase and recovery constraints; no historical cap fallback. Existing endpoint unchanged; custom Intervals CTL/ATL time constants not exposed, so model assumes 42/7. Chart uses exact approved blue #4285df, red #db5461, green #26a269; rendered after stored sessions change. Dates beyond 56-day horizon unavailable. Forecast assumes no unplanned future workouts and omits external calendar entries not in planner. References: https://forum.intervals.icu/t/fitness-tab-graph-legend/93934 and https://forum.intervals.icu/t/calculate-needed-training-load/5788 .

Existing workout preview, actions and forecast layout/colours unchanged.
