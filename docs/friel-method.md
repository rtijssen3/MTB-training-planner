# Friel-inspired planning, v1.1
Friel's original six abilities are not identical to the five tracked metrics. Cadence and force remain workouts, especially Base. Advanced ability focus in Build, with recovery and completed-workout guards preserved. Sources: https://joefrieltraining.com/intervals-part-4/ ; https://joefrieltraining.com/intervals-part-5/ ; https://joefrieltraining.com/build-period-overview/ ; https://joefrieltraining.com/workout-analysis/ ; https://joefrieltraining.com/common-but-confusing-training-terms/ .
Discipline rotation is a coaching heuristic, not prescribed by Friel. XCO emphasizes VO2 and anaerobic work; road balances threshold, VO2 and sprint; gravel emphasizes threshold and long endurance (including preference for longest available slots and using shorter eligible slots for intervals). Sources: https://pubmed.ncbi.nlm.nih.gov/41739301/ ; https://pubmed.ncbi.nlm.nih.gov/33271501/ ; https://www.bikeradar.com/advice/fitness-and-training/gravel-riding-and-racing .
Green targets are maintenance targets relative to personal best, not ability importance, elite benchmarks, or targets to deliberately lose fitness. Blue power scores = best observed 90 days / best observed 365 days, per duration; require a previous-period observation, use W/kg only when weights available across compared efforts, otherwise watts. Average paired durations. 20-minute power and five-minute power are FTP and MAP proxies, not measured FTP or VO2max. Aerobic score = 100*5/max(5, median decoupling) in at least two steady 2–3h rides; 5% guideline, not a validated score. Current scores can underestimate capacity without maximal efforts; never use low score alone to automatically prescribe more intensity. Auto means discipline and phase; manual limiter prioritizes allowed training types. Missing data is unknown, not zero. No cloud schema change. Existing XCM is interpreted as Gravel; persist on save. Legacy exposure analysis is no longer used.
API: https://intervals.icu/api/v1/docs ; athlete activity-power-curves exact seconds; require power_meter true; server emits allowlisted aggregate metrics. Edge Function must be deployed and checked with real data before acceptance. 

Build rotations are indexed by completed plan weeks in the same phase rather than by calendar parity, so scheduled recovery weeks do not skip a rotation step. Actual simulated proposals are regression-tested with a fixed Sunday group ride and equal weekly budget.
