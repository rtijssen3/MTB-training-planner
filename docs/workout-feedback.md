# Adaptive workout feedback
Compare saved sessions from the past 28 days (exclude today) to a unique cycling activity on the date. For power workouts require complete power-zone data, historical FTP, non-overlapping timed intervals and approximate prescribed intensity/duration. Match is an exposure signal only; missing/unmatched intervals never prove failure. Cadence/force require rider feedback. Saved subjective assessment is metadata, not a change to past prescription, and is included in the existing snapshot. Increase by at most one level only when two same-level sessions within 21 days, >=2 days apart, have matching evidence or explicit good feedback and the latest is explicitly rated good/recovered. Too hard reduces one level; unknown holds; no recent level starts N1. Plan levels are caps, not automatic increases. Two-week proposal uses the same historical evidence for both weeks, no assumption about future completion. User confirmation required. No new DB migration or edge deployment.
